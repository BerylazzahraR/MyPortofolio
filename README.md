# 🌐 Personal Portfolio Website

Website portofolio pribadi satu halaman (single-page) yang dibuat menggunakan **HTML5** dan **CSS3** sebagai bagian dari **Web Project I**.  
Project ini berfokus pada struktur semantic, layout modern, dan tampilan yang bersih serta responsif.

---

## ✨ Preview
> Portofolio ini menampilkan profil singkat, informasi tentang saya, serta beberapa project yang pernah saya kerjakan.

---

## 📌 Fitur Utama
- ✅ Single Page Website
- ✅ Struktur **HTML Semantic** (`header`, `main`, `footer`)
- ✅ **Hero Section** dengan judul dan gambar
- ✅ **About Section** (deskripsi diri)
- ✅ **Projects Gallery** (grid minimal 3 item)
- ✅ Navigation bar dengan **Flexbox**
- ✅ Gallery menggunakan **CSS Grid**
- ✅ **Google Fonts** (bukan font default)
- ✅ **Hover effects**
- ✅ **Responsive Design** (mobile friendly)

---

## 🛠️ Tech Stack
- **HTML5**
- **CSS3**
  - Flexbox
  - CSS Grid
  - Media Queries
- **Google Fonts**
